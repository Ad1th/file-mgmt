# Cloudify

Cloudify is a simple and efficient cloud storage solution designed to provide seamless file uploads, folder organization, and intelligent data retrieval using the Gemini API. Built with web technologies, Cloudify offers an easy-to-use interface for managing your files online.

## Features

- **File Uploads:** Upload and store files securely.
- **Folder Organization:** Create and manage folders for better file organization.
- **Search & Retrieval:** Use the Gemini API for enhanced data retrieval.
- **User Authentication:** Secure login and access control.
- **Minimalist UI:** A clean and intuitive user experience.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** JavaScript (Node.js / Express)
- **Database:** Supabase / MongoDB
- **AI Integration:** Gemini API

## Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/cloudify.git
   cd cloudify
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Set up environment variables (create a `.env` file and add required keys):
   ```
   SUPABASE_URL=your_supabase_url
   SUPABASE_KEY=your_supabase_key
   GEMINI_API_KEY=your_gemini_api_key
   ```
4. Run the development server:
   ```sh
   npm start
   ```
5. Open your browser and navigate to `http://localhost:3000`.

## Usage

- Upload files by dragging and dropping or using the upload button.
- Organize files into folders for better management.
- Use the search feature to quickly locate files using AI-powered retrieval.
