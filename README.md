# Cloudify

Cloudify is a simple and efficient cloud storage solution designed to provide seamless file uploads, folder organization. Built with web technologies, Cloudify offers an easy-to-use interface for managing your files online.

## Website:
https://file-mgmt-git-backup11-adith2505-outlookcoms-projects.vercel.app/
## Features

- **File Uploads:** Upload and store files securely.
- **Folder Organization:** Create and manage folders for better file organization.
- **User Authentication:** Secure login and access control.
- **Minimalist UI:** A clean and intuitive user experience.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** JavaScript (Node.js / Express)
- **Database:** Supabase

## Installation

1. Clone the repository.
2. Install dependencies:
   ```sh
   npm install
   ```
3. Set up environment variables.
4. 
5. Run the development server:
   ```sh
   npm start
   ```
6. Open your browser and navigate to `http://localhost:3000`.

## Usage

- Upload files by dragging and dropping or using the upload button.
- Organize files into folders for better management.
- Use the search feature to quickly locate files using AI-powered retrieval.
